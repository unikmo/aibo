# AIBO — Two Products, One Intelligence Core

## Standard — Business Operations Edition
- One customer license contains an industry, one core knowledge pack and one add-on at license level.
- Five pre-provisioned project slots; each location, brand or initiative can use licensed knowledge.
- Expansion to further industries, packs, add-ons or capacity is a paid upgrade.
- License entitlements must be signed/verified by an independent trusted issuer; the local preview cannot activate them by editing a file.
- Interface: `Control-Centre/standard/index.html` served by the local backend.

## Custom — Portfolio Edition
- Soni and all 11 specialists remain shared, with independent project knowledge per project folder.
- Existing 15 projects remain intact; each now includes `PROJECT-KNOWLEDGE.json` referencing its actual or pending industry/core/add-on mapping.
- No standard five-project cap; project-specific commercial terms apply.
- Interface: `Control-Centre/custom/index.html` served by the same backend.

## Shared rules
- The owner primarily uses the Control Centre, not an AI terminal.
- Do not send, publish, incur spend, execute bookings or create contractual obligations without the applicable authorization. Research-based eligible outreach requires separately scoped permission and compliance safeguards.
- Medical mailbox off by default; provider attestation alone does not prove all applicable platform and processor safeguards.
- Both variants must reuse the same specialist runtime, approval rules, and integrations, without making a second copy of Soni.

## Current delivery status
This split is a local integration preview with functional product modes, not a production deployment. Licensing issuance, authentication, true end-to-end guided onboarding, backend approvals, usage billing, live integrations and fully verified agent-to-UI execution remain release blockers. The original recovered UI and its sample data are deliberately preserved in `Control-Centre/original/`.
