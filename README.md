# AIBO

AIBO is a standalone operating system for running multiple business projects. It is designed to be handed to an implementer without any background knowledge of another tool or folder.

Each project has six clear areas: business foundation, market and industry, strategy and targets, delivery, approvals and governance, and results and learning.

The CariFive is the single front door. The owner speaks plainly; AIBO turns that request into research, planning, delivery, review, and a clear next action.
