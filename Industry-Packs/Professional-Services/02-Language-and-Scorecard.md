# Vocabulary, tone and scorecard

## Voice and evidence

Expert, clear, specific, calm and outcome-oriented; avoid inflated guarantees and generic superlatives. Use the client's own terms with verified proof. Distinguish **scope** (work boundary), **deliverables** (outputs), **SOW** (contracted work definition), **change request** (agreed variation), **utilisation** (worked billable hours / available delivery hours), **realisation** (billed value / standard value of chargeable work), **pipeline stage**, **ICP**, **authority content**, **case study** and **thought leadership**.

## KPIs to report (define baselines and source first)

| Metric | Definition | Quality check |
| --- | --- | --- |
| Pipeline value | Sum of open opportunity values, by stage/source/offer | Separate raw from probability-weighted |
| Pipeline velocity | Qualified opportunities × win rate × average deal value / sales-cycle days | Cohort consistency; avoid misleading small samples |
| Win rate | Won / (won + lost) for decided opportunities | Report source/offer, sample size and period |
| Average deal size | Contracted won value / won deals | Distinguish one-off vs annualised retainer |
| Sales cycle | Average days from qualified opportunity to close | Include median and outliers where useful |
| Utilisation | Billable hours / available delivery hours | Define time-off, managers and subcontractors |
| Realisation | Actual invoiced fees / standard value of billable effort | Handle write-offs and discounts consistently |
| Client retention | Retained clients / opening cohort | State logo vs revenue retention |
| Expansion revenue | Incremental recurring or contracted value from existing clients | Exclude replacement/renewal double-count |
| Content-to-lead | Attributable qualified leads / measured content visits or engagements | Attribution and source coverage |
| Referral rate | Referral-origin wins or leads / relevant total | Label denominator explicitly |
| Delivery margin | (Engagement revenue – direct delivery costs) / revenue | Separate gross margin from overhead |
| Capacity utilisation | Committed delivery days/hours / usable capacity | Forecast vs actual, scheduling realism |

**Reporting rule:** Missing inputs remain `Not measured`; never fabricate benchmarks or fill nulls with zero. Report leading indicators, risks, owner and next action monthly; quarterly review for retainers.
