# Management Consulting / Strategy — add-on pack

**Activates on top of:** `Professional-Services` core pack. **Best for:** Strategy, operating model, transformation consultants.

## Specific journey

Mandate and hypothesis → issue tree → workstream charter → evidence gathering → synthesis → steering committee → implementation handoff.

## Additional playbooks and templates

Hypothesis tree; workstream plan; interview guide; steering committee pack; decision log; reusable IP taxonomy.

## Additional KPIs

Time-to-insight; hypothesis validation; workstream delivery; decision adoption; realised value. Use core metric definitions and report missing data honestly.

## Risks / approvals

Separate client evidence from judgement; protect confidential strategy, management data and proprietary frameworks; no fabricated evidence. All Soni / AIBO core approval gates remain controlling; the outreach delegation does not authorise publishing, contractual commitments, financial changes, confidential sharing or new geographies.

## Soni routing rule

Include this add-on's journey, additional templates, specialist evidence and specific risks in briefs and QA checklists. Use this add-on only when verified project services match it. Do not change the project's account permissions merely because the add-on is active.
