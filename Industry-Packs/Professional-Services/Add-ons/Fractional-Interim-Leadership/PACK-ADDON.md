# Fractional / Interim Leadership — add-on pack

**Activates on top of:** `Professional-Services` core pack. **Best for:** Fractional CXOs, interim executives.

## Specific journey

Mandate/authority → stakeholder map → access → 30/60/90-day plan → operating cadence → transition → succession/exit.

## Additional playbooks and templates

Mandate authority matrix; ramp-up plan; stakeholder/board update; decision-rights log; knowledge-transfer and exit checklist.

## Additional KPIs

Time to mandate clarity; milestone achievement; capacity/fee realisation; knowledge-transfer completion. Use core metric definitions and report missing data honestly.

## Risks / approvals

Verify delegated decision/signing authority, conflicts, confidential data access and board claims; no employment/contract promises. All Soni / AIBO core approval gates remain controlling; the outreach delegation does not authorise publishing, contractual commitments, financial changes, confidential sharing or new geographies.

## Soni routing rule

Include this add-on's journey, additional templates, specialist evidence and specific risks in briefs and QA checklists. Use this add-on only when verified project services match it. Do not change the project's account permissions merely because the add-on is active.
