# Coaching & Advisory — add-on pack

**Activates on top of:** `Professional-Services` core pack. **Best for:** Executive coaches, business coaches, advisors.

## Specific journey

Fit and boundary check → goals → session programme → progress review → wrap-up → referral/next programme.

## Additional playbooks and templates

Programme plan; session guide; action commitments; progress measures; group/community variant; nurture sequence.

## Additional KPIs

Attendance; goal progress; programme completion; retention/referrals; cohort engagement. Use core metric definitions and report missing data honestly.

## Risks / approvals

Confidential client/session notes; informed participation; do not imply licensed therapeutic/regulated credentials; respect consent for group sharing. All Soni / AIBO core approval gates remain controlling; the outreach delegation does not authorise publishing, contractual commitments, financial changes, confidential sharing or new geographies.

## Soni routing rule

Include this add-on's journey, additional templates, specialist evidence and specific risks in briefs and QA checklists. Use this add-on only when verified project services match it. Do not change the project's account permissions merely because the add-on is active.
