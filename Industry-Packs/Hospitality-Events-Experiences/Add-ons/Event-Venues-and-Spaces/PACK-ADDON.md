# Event Venues & Spaces — specialised add-on

**Required base:** `Hospitality-Events-Experiences` core pack. **Best for:** Wedding venues, conference centres and unique spaces. Activate only when the project's verified services fit. It supplements rather than replaces core workflows or Soni's existing role.

## Extra operating intelligence
Enquiry, site visit, provisional hold, proposal, signed event agreement, supplier plan, run-of-show; AV and F&B bundles.

## KPI emphasis
Enquiry-to-tour, tour-to-booking, event margin, date utilisation, supplier readiness, deposit aging. Use core definitions, source timestamps and denominators.

## Additional playbooks / artifacts
Venue enquiry qualification; site-visit checklist; event proposal scope; hold calendar; run-of-show. Draft and quality-check without changing external systems unless expressly authorised.

## Special risk controls
Venue capacity, conflicting holds, permits, accessibility, deposits, binding contracts, external suppliers. Never bypass owner approvals for bookings, pricing, compensation, public responses, staffing, contracts or publication. Safety and privacy checks are not optional.

## Soni routing
Adapt the core specialist brief to this subsegment; verify real-time state where applicable, request relevant operational evidence, record risk/conflict and present decision-ready recommendations. Add-on activation does **not** grant credentials, messaging rights or autonomous inventory writes.
