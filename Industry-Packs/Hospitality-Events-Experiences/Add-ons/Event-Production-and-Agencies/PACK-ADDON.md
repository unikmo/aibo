# Event Production & Agencies — specialised add-on

**Required base:** `Hospitality-Events-Experiences` core pack. **Best for:** Event planners, production agencies, corporate event firms. Activate only when the project's verified services fit. It supplements rather than replaces core workflows or Soni's existing role.

## Extra operating intelligence
Client brief and creative approval; workstreams; supplier and production dependencies; multi-day logistics; retrospective.

## KPI emphasis
Gross event margin, supplier on-time, schedule variance, change requests, client satisfaction. Use core definitions, source timestamps and denominators.

## Additional playbooks / artifacts
Production brief; supplier scope tracker; multi-day production schedule; client approval register; post-event report. Draft and quality-check without changing external systems unless expressly authorised.

## Special risk controls
Contracted scope and rights, subcontractor costs, venue safety, production change orders and public claims. Never bypass owner approvals for bookings, pricing, compensation, public responses, staffing, contracts or publication. Safety and privacy checks are not optional.

## Soni routing
Adapt the core specialist brief to this subsegment; verify real-time state where applicable, request relevant operational evidence, record risk/conflict and present decision-ready recommendations. Add-on activation does **not** grant credentials, messaging rights or autonomous inventory writes.
