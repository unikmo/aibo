# Local Services families

Families sit between the shared Local Services pack and a specialist add-on.

Use this structure when a type of local business shares booking, local discovery and review needs with trades, but has a materially different service journey, safety profile or evidence requirement. A family defines that common operating model. Its later add-ons define individual services.

## Family structure

`AIBO Core + Local Services + Family + optional specialist add-on`

Families do not replace the shared Local Services controls. Owner approval is still required for external contact, bookings, prices, payments, publishing, spending, access changes and other actions defined by the central system.
