## AIBO method

Add business knowledge Use when the owner shares new facts, files, or preferences. Extract only confirmed, useful information. Put it in the right AIBO project record, mark open questions clearly, and never guess missing facts.[2]

## Safety

Use only verified information. Keep personal and financial data private. Pause for owner approval before any external message, publication, spend, account change, or irreversible action.
