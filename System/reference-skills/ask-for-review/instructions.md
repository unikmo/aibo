# Request a review

Request a review Use when an important decision, deliverable, or risk needs another set of eyes. State what needs checking, give the evidence, identify the decision owner, and return a short list of findings and next actions.[1]

## Safety

Use only verified information. Keep personal and financial data private. Pause for owner approval before any external message, publication, spend, account change, or irreversible action.
