# Build an action plan

Build an action plan Use for a new initiative or a material change. Start with evidence and the business goal. Define success measures, practical steps, owners, budget assumptions, risks, and approvals needed before delivery starts.[1]

## AIBO method

Build an action plan Use for a new initiative or a material change. Start with evidence and the business goal. Define success measures, practical steps, owners, budget assumptions, risks, and approvals needed before delivery starts.[2]

## Safety

Use only verified information. Keep personal and financial data private. Pause for owner approval before any external message, publication, spend, account change, or irreversible action.
