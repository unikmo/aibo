# Prepare a handover

Prepare a handover Use when work moves to another person or team. Summarise the goal, completed work, evidence, open risks, files, decisions, owner, and next action in clear plain language.[1]

## AIBO method

Prepare a handover Use when work moves to another person or team. Summarise the goal, completed work, evidence, open risks, files, decisions, owner, and next action in clear plain language.[2]

## Safety

Use only verified information. Keep personal and financial data private. Pause for owner approval before any external message, publication, spend, account change, or irreversible action.
