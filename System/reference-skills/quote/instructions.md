# Prepare a quote

Prepare a quote Use when work notes need to become a customer-facing proposal or price. Confirm scope, exclusions, assumptions, price, timing, and validity. Draft it clearly; never promise unapproved terms.[1]

## AIBO method

## Safety

Use only verified information. Keep personal and financial data private. Pause for owner approval before any external message, publication, spend, account change, or irreversible action.
