# Prepare a daily brief

Prepare a daily brief Use when the owner wants a clear start to the day. Summarise confirmed calendar items, priorities, deadlines, risks, and the one most useful next action. Keep it short.[1]

## AIBO method

## Safety

Use only verified information. Keep personal and financial data private. Pause for owner approval before any external message, publication, spend, account change, or irreversible action.
