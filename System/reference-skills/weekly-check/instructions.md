# Run a weekly review

Run a weekly review Use to review progress across a project. Report completed work, evidence, results, spending, risks, delays, decisions needed, and the next-week priority. Keep the report factual.[1]

## Safety

Use only verified information. Keep personal and financial data private. Pause for owner approval before any external message, publication, spend, account change, or irreversible action.
