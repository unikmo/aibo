# Turn notes into action

Turn notes into action Use when the owner provides meeting notes or a recording summary. Separate decisions, actions, owners, deadlines, and unresolved questions. Do not invent commitments that were not stated.[1]

## Safety

Use only verified information. Keep personal and financial data private. Pause for owner approval before any external message, publication, spend, account change, or irreversible action.
